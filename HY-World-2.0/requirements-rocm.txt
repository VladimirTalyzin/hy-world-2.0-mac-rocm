# come from AMD's wheel index (or the `rocm-sdk` wheels) *before* this file:

#   pip install --index-url https://rocm.nightlies.amd.com/v2/gfx1151/ \

# downgrade/replace a working ROCm stack.

#                   gfx1151 (Radeon 8060S / Strix Halo), Windows 11.
